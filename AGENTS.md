# Instructions for AI agents

This repository documents a long-running, hands-on engineering exploration.

## Before working
1. Read `agentic-memory/INDEX.md`.
2. Read only the memory files relevant to the task.
3. Check `PROJECT_STATUS.md` and the latest relevant session note before proposing changes.
4. Treat recorded results as observations, not verified ground truth. Preserve uncertainty and distinguish measured, calculated, and assumed values.

## Working principles
- Teach the underlying engineering concepts, not just software操作 steps.
- Prefer small, controlled experiments and compare simulations with analytical estimates where possible.
- Do not silently overwrite previous experiment results or historical notes.
- Record software versions, geometry, units, material properties, boundary conditions, mesh settings, solver settings, and relevant output values.
- When a result is approximate or rounded, say so. Do not invent precision.
- Keep `PROJECT_STATUS.md` as the concise current-state summary.
- Add dated notes under `agentic-memory/sessions/` for substantial work. Update technical notes and `agentic-memory/INDEX.md` when their contents or structure change.
- Keep personal details minimal. Do not add private employment, financial, health, or identifying information unless explicitly requested.
- Ask before making destructive changes or restructuring existing experiment data.

## Documentation conventions
- Use Markdown.
- Include units explicitly.
- Separate facts, assumptions, interpretations, and open questions.
- Link related files with relative Markdown links.
- Do not treat this memory as a verbatim transcript. Preserve durable context, decisions, lessons, and unresolved questions.
