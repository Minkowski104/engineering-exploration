# Project history

## Purpose
This repository is a durable record of practical exploration of engineering disciplines and the software used to model, simulate, and understand physical systems.

## Work completed so far
- Installed and configured FreeCAD on an Intel Mac.
- Configured the CalculiX solver bundled with FreeCAD.
- Built a rectangular cantilever beam model.
- Assigned steel material properties, created a mesh with Netgen, applied a fixed support and an end load, and solved the FEM model.
- Examined displacement and von Mises stress.
- Refined the mesh and compared simulation results with Euler–Bernoulli beam theory.
- Created this Git repository with a README, project status, experiment log, and the initial FreeCAD model.
- Began setting up `agentic-memory/` so future AI-assisted sessions can recover durable context.

## Current direction
Finish a small number of controlled structural-mechanics experiments, document them, then broaden into introductory CFD with OpenFOAM. The sequence is exploratory, not a rigid curriculum.

## Repository conventions
- `PROJECT_STATUS.md`: concise snapshot of current state and next steps.
- `EXPERIMENT_LOG.md`: experiment records and comparisons.
- `structural-mechanics/`: structural analysis models and results.
- `fluid-mechanics/`: future CFD work.
- `thermal-analysis/`, `cad/`, `robotics/`: future exploration areas.
- `agentic-memory/`: durable context, decisions, technical setup, and session summaries.
