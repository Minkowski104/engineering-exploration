# Project decisions

## Use Git as the durable project record
Keep models, notes, and curated AI memory in the engineering-exploration repository. Chat history is useful, but should not be the only record.

## Use Markdown memory before vector search
Start with small, human-readable Markdown files and an index. Consider embeddings / vector retrieval only when the memory corpus becomes large enough that ordinary file search and index navigation are insufficient.

## Curated memory, not raw transcript dumps
Preserve durable context, technical findings, decisions, failed approaches that explain later choices, and open questions. Do not indiscriminately archive every conversational turn.

## Mac-first where practical
Use the Intel Mac as the default learning environment when the software supports it adequately. Use Windows/Linux when a clear technical advantage justifies the switch.

## Explore broadly before specializing
Use practical projects across mechanics, fluids, thermal analysis, CAD, and robotics to discover which areas are most compelling.
