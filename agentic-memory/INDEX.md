## Maintenance
At the end of a substantial session:
1. Update the relevant technical or decision note.
2. Add a dated session note summarizing what changed, what was learned, and what remains open.
3. Update `PROJECT_STATUS.md` if the current project state changed.
4. Update this index when files are added, renamed, or removed.

Prefer concise, structured summaries over full transcripts. Keep important failed attempts when they explain why a later approach was chosen.
